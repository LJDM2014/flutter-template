# 发布说明（草稿）

> 版本：vNext（发布前替换为实际版本号）
> 日期：2026-10-22
> 主题：安全加固 —— 传输加密、令牌保护、连接可靠性

---

## 概览

本次发布完成四项安全与可靠性修复（对应《架构风险评估报告》P0/P1 全部条目）：局域网内所有通信默认走 TLS 加密；登录令牌不再以明文形式存储在服务端与本机；断线后客户端永不放弃重连，网络恢复即自动回到在线状态。

## 新特性

### 🔒 传输全程加密（默认开启）

- 桌面端中继首次启动自动生成 RSA-2048 自签证书，后续 WebSocket（wss）与 REST（https）均以 TLS 加密传输，同网段无法再嗅探消息内容与登录凭据；
- 连接页显示服务器是否为加密连接；
- 若证书生成失败，中继自动降级为明文模式以保证可用，并在连接页明确提示。

### 🔑 登录令牌安全存储

- **服务端**：会话文件只保存令牌的 SHA-256 摘要——文件泄露不再等于身份泄露；
- **客户端**：登录令牌存入系统安全存储（Windows 凭据保护 DPAPI / Android Keystore），不再写入明文配置文件；旧版本已保存的令牌会在首次启动时自动迁移，无需任何操作；
- 修改密码后其他设备自动登出（原有行为保持）。

### 🔁 断线重连永不放弃

- 修复旧版「重连若干次后彻底放弃、需要手动重连」的问题：退避重连耗尽后自动转入每 60 秒一次的慢速重连，中继恢复后无需任何操作即可回到在线；
- 断线期间发出的消息保持「发送中」状态，重连成功后自动补发；界面会区分「Xs 后重连」与「每 60s 自动重连」两种提示。

## 升级须知（重要）

1. **中继服务端升级后，所有存量用户需重新登录一次**：旧版会话文件中的令牌无法安全迁移（新旧格式无法区分），属一次性影响。
2. **桌面客户端**：旧令牌自动迁移到系统安全存储，无感升级。
3. **Web 端使用加密中继时**：浏览器无法自动信任自签证书，首次使用需先用浏览器访问一次中继地址并信任证书（连接页有提示）；未操作则自动回退明文地址。
4. 同设备重新登录仍会使旧连接失效（多设备同时在线互不影响，行为不变）。

## 已知限制

- 自签证书在桌面端由客户端主动信任，不提供服务器身份校验（同网段攻击者理论上可伪造中继）；后续版本考虑证书指纹固定（TOFU）。
- Web 端令牌存储依赖浏览器 localStorage，隔离边界为同源策略。
